# OverCite v0.3.3

Short version: faster follow-up citations, clearer result metadata, and stronger simple-search ranking.

## Highlights

- Browser users can enable `Return to source file after insert` to switch back to the original `.tex` editor after OverCite updates the bibliography.
- The browser popup now dismisses as soon as insertion finishes when return-to-source is enabled, so rapid follow-up citations are not blocked by the result UI.
- Result cards show citation-count badges when provider metadata is available.
- arXiv results can pick up citation counts from ADS/SciX when an ADS/SciX token is configured, with a short timeout so simple search remains responsive.
- Simple search ranking is stronger for title evidence, hyphenated author keys, duplicate records across sources, and paper-vs-catalog distractors.
- The Physics preset uses ADS/SciX first when configured, then Crossref and arXiv if needed. INSPIRE remains available only through custom routing.
