# OverCite v0.3.6

Browser performance hotfix for Overleaf's current interface.

## Fix

- File-navigation tracking now stays dormant outside citation insertion.
- OverCite no longer scans broad PDF, editor, or grammar-tool DOM ancestors on every pointer interaction.
- Real file-tab and file-tree navigation during insertion is still respected, so OverCite does not pull users away from a file they deliberately selected.

## Validation

- Full browser-extension test suite.
- Packaged Chrome regression for both return-to-source modes.
- Packaged Chrome regression for a user changing files during insertion.
- Large unrelated PDF/grammar DOM regression with zero filename-text reads while insertion is idle.
- Firefox lint with warnings treated as errors.
- Browser-package archive, checksum, syntax, and Firefox source-rebuild checks.
