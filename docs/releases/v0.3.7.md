# OverCite v0.3.7

Browser reliability update for literature search and Overleaf bibliography switching.

## Fixes

- Contextual ADS/SciX lookup now starts with both the raw surname and a likely punctuation variant, returns as soon as a high-confidence paper is found, and cancels slower work.
- ADS/SciX requests, response bodies, exports, and the complete routed literature search have explicit internal deadlines. The popup now reports a slow search instead of incorrectly claiming that the Firefox background worker died.
- OverCite pairs the visible CodeMirror editor with its controlling filename during tab transitions. A selected `refs.bib` label can no longer be combined with the previous source editor.
- Automatic file switching and chained source recovery use hard shared deadlines. Unknown editor identity requires explicit manual confirmation, and writes are bound to the confirmed editor identity and navigation state.
- Late page responses are idempotent: if Overleaf already applied an initial source write, bibliography write, or collision-key rewrite, OverCite verifies the result instead of duplicating or rejecting it.

## Search default

- New browser installs, including Chrome, Firefox, and the local Safari build, start in `Simple search` for non-empty citation keys.
- Existing saved browser preferences are preserved; this release does not force current users away from Contextual search.
- Empty `\cite{}` lookups remain Contextual because they need sentence context.
- VS Code and TeXstudio defaults are unchanged in this browser release.

## Validation

- Full browser-extension unit and build suite.
- Packaged Chrome regressions for both return-to-source modes, delayed CodeMirror transitions, missing identity, a wrong blank editor, verified manual continuation, navigation after manual confirmation, collision-key late acknowledgments, visible mode actions, and empty-token mode selection.
- Prior-slowdown stress checks: 75 trusted idle clicks and 50 trusted insertion-time clicks in Chrome caused zero large-DOM text reads; genuine Firefox executed 2,000 idle and 2,000 insertion-time pointer-handler calls without measurable slowdown.
- Genuine Firefox runs of the same critical editor-switch, editor-identity race, late-write, and mode-selection paths.
- Firefox extension lint with warnings treated as errors.
- Browser-package syntax, version, archive, checksum, and source-rebuild checks.
