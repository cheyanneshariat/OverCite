# OverCite v0.3.5

Short version: browser compatibility fix for Overleaf's current editor tabs.

## Highlights

- Fixed active-editor detection when Overleaf reports both its sidebar and source editor tabs as selected.
- Citation resolution now follows the active editor-file tab and its controlled CodeMirror panel instead of a stale focused editor.
- Hidden editors and ambiguous toolbar text can no longer redirect writes to unrelated files such as `old_text.tex`.
- Source and bibliography writes now require exact path-aware filename matches.
- Result metadata is rendered with explicit DOM nodes instead of dynamic HTML.
- Firefox 142 is now the declared minimum, matching the manifest's data-collection permission metadata.
- Added a real-Chrome regression fixture covering `Rice2021`, bibliography insertion, stale-editor isolation, and both return-to-source settings.

## Packages

- `overcite-chrome-0.3.5.zip`
- `overcite-firefox-0.3.5.zip`
- `overcite-firefox-source-0.3.5.zip`

The VS Code extension is unchanged because this fix is specific to Overleaf's browser UI.
