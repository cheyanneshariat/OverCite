# OverCite v0.3.4

Short version: browser hotfix for result merging.

## Highlights

- Fixed a Chrome/Firefox runtime error that could show `preferredCitationCount is not defined` when duplicate results from multiple sources were merged.
- Kept citation-count metadata on merged result cards by preserving the best available count.
- Failed lookups now show a retryable popup state instead of leaving a stale spinner.
- Background-worker timeout messages now tell users to refresh the Overleaf page and try again.
- Hidden timeout toasts are removed after fade-out so they do not linger in browser UI state.

## Packages

- `overcite-chrome-0.3.4.zip`
- `overcite-firefox-0.3.4.zip`
