# OverCite v0.3.8

Browser hotfix for Overleaf's current editor-tab structure.

## Fixes

- Restores automatic switching to `refs.bib` when Overleaf uses one persistent CodeMirror editor and selected tabs without `aria-controls`.
- Requires the editor document or identity to transition after an automatic file click, then verifies the active filename and expected document before writing.
- Keeps the v0.3.7 protections for delayed transitions, wrong blank editors, manual confirmation races, and late write acknowledgments.
- New browser installs without a saved or synced preference return to the original source `.tex` file after insertion by default. Existing saved choices remain unchanged.

## Validation

- Full browser-extension unit and build suite.
- Packaged Chrome and Firefox scenarios modeled on current Overleaf: one persistent editor, selected tabs without `aria-controls`, return-to-source on and off, and a delayed document transition.
- Existing wrong-editor, manual-navigation, late-write, empty-citation, contextual-search, and large-DOM slowdown regressions.
- Firefox extension lint with warnings treated as errors, archive integrity, source rebuild, and SHA-256 checks.
