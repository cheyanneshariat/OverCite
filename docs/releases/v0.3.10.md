# OverCite browser v0.3.10 and VS Code v0.3.5

This release adds a restrained acknowledgment reminder to Chrome, Firefox, and VS Code.

## User-visible behavior

- New and existing users see the reminder after their first successful citation insertion following the update.
- The reminder is dismissible and includes a `Copy acknowledgment` action.
- Once shown, it does not appear again for this reminder version.
- The shown receipt is stored locally. OverCite does not send usage, manuscript, or acknowledgment activity anywhere.
- Citation insertion completes independently of the reminder. Storage and clipboard failures cannot turn an insertion into an error.

The copied text is:

```tex
This work made use of \texttt{OverCite} \citep{Shariat2026}, an in-editor citation tool for \LaTeX.
```

- Full browser unit and build suite, including concurrent claims, update users, stored suppression, and storage failure.
- Packaged Chrome and genuinely installed Firefox scenarios for the first post-update reminder, dismissal, stored suppression, and insertion-safe storage failure.
- Existing Chrome and Firefox editor-switch, stale-editor, delayed-write, manual-navigation, search-mode, and large-DOM slowdown regressions.
- VS Code syntax checks, unit tests, local-workspace extension-host scenarios, and an Overleaf Workshop-style virtual-filesystem scenario.
- Firefox lint with warnings treated as errors, package integrity, clean source rebuild, and SHA-256 checks.
