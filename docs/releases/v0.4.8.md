# OverCite v0.4.8 maintenance release

Chrome/Firefox 0.4.8 and VS Code 0.4.6.

- Unconfigured non-empty lookups start in Simple Search. Empty citations still use contextual search.
- Classic is the default contextual engine; Context Beta is explicitly experimental and opt-in. Existing explicit preferences are preserved.
- Full paper titles in Simple Search are queried as titles rather than author names.
- Result cards remain stable while optional metadata arrives. Source edits and settings changes invalidate stale results.
- Bibliography insertion preserves available volume, issue, and page metadata, with safeguards against stale editor targets.
- VS Code's initial keyboard selection and empty-citation routing are corrected.

Review suggestions before inserting. Contextual discovery, particularly for common author-year names and ambiguous prose, is not guaranteed. This release does not claim to solve that limitation.

Safari 0.4.8 is an unsigned local preview, not an App Store release. TeXstudio 0.4.6 is a preview pending a native editor/macros acceptance check. Do not advertise either as a newly certified stable platform.

GitHub packages and store distribution are separate. Chrome/Firefox ZIPs are unsigned packages for store submission or developer testing, not signed store installs. Store review, signing, and verification of the distributed update remain separate requirements. The VSIX can be installed manually in VS Code. Safari and TeXstudio source is included as preview-only.
